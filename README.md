# 💎 MetalPrice Pulse (글로벌 금속 실시간 시세 및 기간별 변동 분석 웹 앱)

> 국제 원자재 시장의 주요 귀금속(금, 은, 플래티넘, 팔라듐) 및 산업용 금속(구리, 알루미늄 등)의 실시간 시세 조회 및 기간별 세로형 변동 차트 분석 플랫폼입니다.

---

## 🌟 핵심 기능 및 특징

1. **상단 실시간 카드뷰 (Card View Grid)**
   - 금(Gold), 은(Silver), 구리(Copper), 플래티넘(Platinum), 팔라듐(Palladium), 알루미늄(Aluminium)의 실시간 호가 및 24H 변동률(%) 표시
   - 실시간 가격 변동 시 호가 펄스(초록/빨강 플래시) 애니메이션
   - 금속별 고유 메탈릭 글로우 디자인
   - 카드 클릭 시 하단 해당 금속의 세로 차트로 부드러운 스크롤 이동

2. **OpenAPI (MetalpriceAPI) 정밀 연동**
   - MetalpriceAPI (`https://metalpriceapi.com`) 엔드포인트 연동
   - [API 설정] 모달을 통해 사용자 고유 API 키 입력 및 연결 테스트 가능
   - 로컬 스토리지에 안전하게 암호화 보관
   - API 키 미입력 또는 쿼터 제한 시에도 고정밀 시뮬레이터로 무중단 작동

3. **다양한 기간 선택 필터 (Timeframe Controller)**
   - `1주일(7D)`, `1개월(1M)`, `3개월(3M)`, `6개월(6M)`, `1년(1Y)`, `연초대비(YTD)`, `5년(5Y)`
   - 기간 선택 시 하단의 모든 개별 세로형 차트가 즉각 동기화되어 고해상도 시계열 데이터 재렌더링

4. **하단 금속별 세로형 개별 차트 스택 (Vertical Stack Charts)**
   - 금, 은, 구리, 플래티넘 등의 시세 변동 그래프가 **세로로 1개씩 순차 배치**
   - 스플라인(Spline) 곡선 및 금속별 그래디언트 영역 채우기
   - 일자별 정밀 인터랙티브 툴팁 및 크로스헤어
   - 기간 내 **최고가(High), 최저가(Low), 평균가(Avg), 기간 변동률(%)** 통계 뱃지 제공
   - 차트 이미지(PNG) 및 데이터셋(CSV) 내보내기 기능 탑재

5. **실시간 원화(KRW) 환율 OpenAPI 연동 & 단위 환산**
   - **실시간 환율**: 글로벌 외환 OpenAPI(`open.er-api.com`)를 연동하여 실시간 USD/KRW 환율(예: `1 USD = ₩1,348.60`)을 즉각 반영
   - **통화 기준 (원화 디폴트)**: `원화 (₩ · KRW)` 기본 선택, `달러 ($ · USD)`, `엔화 (¥ · JPY)`, `위안화 (¥ · CNY)` 지원
   - **중량 단위 (그램 디폴트)**: `그램 (g)` 기본 선택, `온스 (Troy oz · 31.1g)`, `돈 (1돈 · 3.75g · 국내 기준)` 지원

## 🚀 실행 방법

### 방법 1. 브라우저로 직접 열기
- 프로젝트 폴더 내의 [`index.html`](file:///c:/Users/%EC%9A%B0%EB%A6%AC%EC%A7%91/Desktop/SDU/2%ED%95%99%EB%85%84%202%ED%95%99%EA%B8%B0/04.%EB%B0%94%EC%9D%B4%EB%B8%8C%EC%BD%94%EB%94%A9/%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B807/index.html) 파일을 더블 클릭하거나 브라우저(크롬, 엣지 등)로 드래그하여 실행합니다.

### 방법 2. 로컬 웹 서버 실행 (권장)
VS Code의 `Live Server` 확장 또는 Python/Node 간이 서버를 사용할 수 있습니다.
```bash
# Python 내장 서버
python -m http.server 3000

# Node.js http-server
npx http-server -p 3000
```
브라우저에서 `http://localhost:3000` 접속
